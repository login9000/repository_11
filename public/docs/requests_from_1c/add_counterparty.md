# Создание контрагента

> Метод **PUT**

[filename](../_auth.md ":include")

Для создания нового контрагента необходимо отправить JSON запрос на адрес

> /api/v2/add_counterparty

Содержимое запроса должно быть следующее:

```json
{
    "Данные": {
        "ГоловнойКонтрагентИД": "1944da0e-7998-11e2-b6fa-6805ca04de77",
        "КонтрагентИД": "1944da0e-7998-11e2-b6fa-6805ca04de77",
        "Статус": "1",
        "Назввание": "Лысковское районное потребительское общество222",
        "ИНН": "5222011236",
        "КПП": "522201000",
        "ОГРН": "522201000",
        "АдресРегистрации": "606210, Нижегородская обл, Лысковский р-н, Лысково г, Ленина ул, дом № 42",
        "АдресФактический": "606210, Нижегородская обл, Лысковский р-н, Лысково г, ул. Крылова 25 магазин &quot;Теремок&quot;",
        "КоррСчет": "30101810900000000609",
        "БанкБик": "042202604",
        "БанкИмя": "ВОЛГО-ВЯТСКИЙ БАНК СБЕРБАНКА РОССИИ",
        "БанкНомерСчета": "40702810042200100041",
        "АдресДоставкиИД": "a7ae3cf3-7594-4a5c-b19d-75645a5529a7",
        "ПроцентБонуса": "10"
    }
}
```

## Описание полей

**Обязательные поля**:

-   **ГоловнойКонтрагентИД** — ID головного контрагента в 1С в формате UUID
-   **КонтрагентИД** — ID контрагента в 1С в формате UUID
-   **Статус** — Статус контрагента (подтверждение), только числовое значение 0 или 1
-   **Назввание** — Название контрагента
-   **Инн** — ИНН контрагента
-   **АдресРегистрации** — Адрес регистрации контрагента

**Необязательные поля**:

-   **КПП** — КПП контрагента
-   **ОГРН** — ОГРН контрагента
-   **АдресФактический** — Фактический адрес контрагента
-   **КоррСчет** — Корреспонденсткий счет контрагента в банке
-   **БанкБик** — Бик банка контрагента
-   **БанкИмя** - Название банка контрагента
-   **БанкНомерСчета** — Номер банковского счета контрагента
-   **АдресДоставкиИД** — ID адреса доставки дл контрагента
-   **ПроцентБонуса** — процент бонусов, число int или float


## Результат выполнения

В случае успешного выполнения запрос, ответ будет: **Контрагент создан**

## Ошибки

-   **Данный контрагент уже существует, воспользуйтейсь методом для обновления** — ошибка пояляется если контрагент с таким же ID уже добавлен в ЛК.
-   **Не указан ГоловнойКонтрагентИД и КонтрагентИД** — необходимо указать обязательные поля **ГоловнойКонтрагентИД** и **КонтрагентИД**
-   **Произошла ошибка при создании контрагента** — означает что, что-то произошло при сохранении данных, но это не относится к структуре запроса и данных в нём.
