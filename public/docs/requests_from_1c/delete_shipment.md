# Удаление отгрузки

> Метод **PUT**

[filename](../_auth.md ":include")

Для удаления отгрузки необходимо отправить JSON запрос на адрес

> /api/v2/delete_shipment

Содержимое запроса должно быть следующее:

````json
{
    "Данные": {
        "ГоловнойКонтрагентИД": "c31f2b47-7559-11e9-80da-000c29ac4925",
        "ОтгрузкаИД": "0c134957-6385-11ef-8148-000c29ac4925"
    }
}
````

## Описание полей

**Обязательные поля**:

-   **ГоловнойКонтрагентИД** — ID головного контрагента в 1С в формате UUID
-   **ОтгрузкаИД** — ID отгрузки в 1С формате UUID.

## Результат выполнения

В случае успешного выполнения запрос, ответ будет: **Отгрузка удалена**

## Ошибки

-   **Поля ГоловнойКонтрагентИД и ОтгрузкаИД не заполнены** — необходимо заполнить обязательные поля
-   **Такой ГоловнойКонтрагентИД отсутсвует** — означает что такого контрагента у отгрузок нет в ЛК
-   **Отгрузка с таким ID не найдена** — означает что отгрузка с таким ID несуществует в ЛК
