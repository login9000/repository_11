# Обновление данных пользователя

> Метод **PUT**

[filename](../_auth.md ":include")

Для изменения данных пользователя необходимо отправить JSON запрос на адрес:

> /api/v2/update_user_data

Содержимое запроса должно быть следующее:

```json
{
    "Данные": {
        "ПользовательИД": "4287c1d2-b874-11eb-811a-000c29ac4925",
        "Имя": "Тест",
        "Фамилия": "Тест",
        "Отчество": "Тест",
        "Роль": "Сотрудник",
        "НовыйПароль": "aSsRnN-p7dBpk",
        "Email": "test@test.ru",
        "Менеджер": {
            "ФИО": "Тест Тест Тест",
            "Email": "test@test.ru",
            "МенеджерИД": "4287c1d2-b874-11eb-811a-000c29ac4925"
        },
        "ГоловнойКонтрагентИД": "4287c1d2-b874-11eb-811a-000c29ac4925",
        "СотрудникиДобавитьИлиОбновить": {
            "e1312736-ca6f-11ee-8144-000c29ac4925": {
                "ДелегироватьУведомление": "ead0a953-ca70-11ee-8144-000c29ac4925",
                "Заблокирован": "0"
            },
            "6b3c480b-a256-11ef-814c-000c29ac4925": {}
        },
        "СотрудникиУдалить": [
            "e1312736-ca6f-11ee-8144-000c29ac4925",
            "e1312736-ca6f-11ee-8144-000c29ac4926"
        ],
        "Заблокирован": "0"
    }
}
```

## Описание полей

-   **ПользовательИД** — ID пользователя в 1С
-   **Данные** — корневой корневой элемент который должен содержать
-   **Имя**, **Фамилия**, **Отчество** — Поля для указания ФИО пользователя, при этом чтобы поменять ФИО пользователя, то необходидимо заполнить все три поля. При незаполнении какого-либо поля, ФИО пользователя не поменяется.
-   **Роль** — Может содержать только следующие значения:

[filename](../_user_roles.md ":include :type=code text")

-   **НовыйПароль** — Новый пароль пользователя, данный пароль должен быть больше или равен 8 символам, содержать символ в верхнем и нижнем регистре, а так же цифру.
-   **Email** - Email пользователя
-   **Менеджер** — поле с вложенными полями: **ФИО**, **МенеджерИД**, **Email**. Данные поля могут быть заполненны по одному и все сразу.
-   **ГоловнойКонтрагентИД** — ID головного контрагента из 1С
-   **СотрудникиДобавитьИлиОбновить** - поле с вложенными полям. В данном поле могут содержаться ID пользователей которые необходимо либо добавить как сотрудника для пользователя с ID из поля **ПользовательИД** , так обновить параметры уже добавленного сотрудника с помощью полей:

1. **ДелегироватьУведомление** — позволяет указать ID пользователя/сотрудника которому делегируются уведомления. Может сожержать пустое значение для отключения делегирования. **(Необязательное поле)**

2. **Заблокирован** — позволяет указать заблокирован ли пользователь или нет. Данное поле может принимать 2 значения: **0** — не заблокирован, **1** — заблокирован. **(Необязательное поле)**

-   **СотрудникиУдалить** - поле которое может содержать ID пользователей которых необходимо удалить из списка сотрудников у пользователя с ID из поля **ПользовательИД**
-   **Заблокирован** - поле в котором можно указать заблокирован пользователь или нет. Данное поле может принимать 2 значения: **0** — не заблокирован, **1** — заблокирован

## Результат выполнения

В случае успешного выполнения запрос, ответ будет: **Успешное сохранение**

## Ошибки

Возможно несколько вариантов ошибок:

- **Произошла ошибка при сохранении** — означает что, что-то произошло при сохранении, но это не относится к структуре запроса и данных в нём. 
- **Не указан ID** - возникает в случае если неуказано поле **ПользовательИД**.
- **Статус указан не правильно. Статус может иметь значения** - возникает если значение поля **Роль** заполненно некорректно. 
- **Пользователь с таким ID отсутствует** - возникает если указанного пользователя нет в ЛК.
- **Поле — Данные — пустое** — может возникать если данные не содержат корневое поле **Данные**, либо если структура запроса нарушена синтаксически, то есть некорректная JSON структура.
- Ошибки связанные с паролем: **Пароль должен содержать 8 символов**, **В пароле должен быть символ в верхнем регистре**, **В пароле должен быть символ в нижнем регистре**, **Пароль должен содержать цифры**. В описании ошибок указанная проблема из-за которой они возникли.
