# Обновление номенклатуры

> Метод **PUT**

[filename](../_auth.md ":include")

Для создания нового заказа необходимо отправить JSON запрос на адрес

> /api/v2/update_catalog_item

Содержимое запроса должно быть следующее:

```json
{
    "Данные": {
        "ОсновнойРазделИД": "59eaed51-3c06-11ee-8143-000c29ac4925",
        "СкладИД": "00000000-0000-0000-0000-000000000000",
        "НоменклатураИД": "0a867d89-fd2d-11e4-8044-40167e7a5fac",
        "ВидНоменклатурыИД": "db496234-eaf6-11ea-8109-000c29ac4925",
        "Наименование": "Лист RAL 5021 (Стандарт)*1250*",
        "Толщина": "0,4",
        "ЦветИД": "103adaed-0173-11e3-b353-50e549ac2567",
        "ЕдиницаИзмеренияНаименования": "пог. м",
        "НедоступноДляВыбора": false,
        "ОстаткиПоМеталлу": true,
        "ОстаткиВШтуках": false,
        "ЗаполнятьХарактеристику": true,
        "ПродаетсяКомплектами": false,
        "КоличествоШтукВКомплекте": 0,
        "КоэффициентПересчетаКоличества": 1,
        "КоэффициентПересчетаМетрКвадратные": 1.25,
        "Свойства": {
            "Профиль": "Лист гладкий",
            "Толщина": "Стандарт",
            "Покрытие": "RAL",
            "Цвет": "RAL 5021"
        }
    }
}
```

## Описание полей

**Обязательные поля**:

-   **ОсновнойРазделИД** — ID основного раздела каталога в 1С в формате UUID
-   **СкладИД** — ID склада в формате UUID

**Необязательные поля**:

Остальные поля добавляются в элемент номенклатуры как указаны в запросе и каких-либо проверок не происходит. То есть все поля кроме **ОсновнойРазделИД** и **СкладИД** добавляются в элемент номенклатуры если номенклатуры с полем **НоменклатураИД** нет в указанном разделе/складе.

## Результат выполнения

В случае успешного выполнения запрос, ответ будет: **Номенклатура добавлена в каталог**

## Ошибки

-   **Не указаны поля ОсновнойРазделИД и СкладИД** — необходимо заполнить соответствующие поля.
-   **Произошла ошибка при загрузке каталога** — проблема в базе данных ЛК.
-   **Каталог в базе данных пустой или неявляется корректной структурой** — загруженный ранее каталог пустой в базе данных ЛК.
-   **Номенклатура уже есть в каталоге** — происходит если в базе данных в каталоге уже есть указанная номенклатура с указанным полем **НоменклатураИД**.
-   **Произошла ошибка при сохранении каталога** — проблема при сохранении данных в базу данных в ЛК.
