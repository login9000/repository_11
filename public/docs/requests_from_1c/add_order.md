## Описание полей

**Обязательные поля**:

-   **ДатаСоздания** — Дата создания заказа в 1С можно передавать в формате что указан в примере JSON запроса. Можно использовать любой другой формат, на стороне API дата сначала преобразуется в timestamp.
-   **ПользовательИД** — ID пользователя в 1С формате UUID.
-   **ЗаказПокупателяИД** — ID заказа в 1С в формате UUID.
-   **НомерЗаказа** — Номер заказа в 1С, не является ID в формате UUID.
-   **КонтрагентИД** — ID контрагента из 1С в формате UUID.
-   **НаличнаяОплата** — Признак оплаты наличными, значения только 0 или 1.
-   **ДатаОтгрузки** — Дата отгрузки формате что указан в примере JSON запроса. Можно использовать любой другой формат, на стороне API дата сначала преобразуется в timestamp.
-   **СкладОтгрузкиИД** — Склад отгрузки в 1С в формате UUID.
-   **Доставка** — Признак доставки, значения только 0 или 1. Если указано 1, то необходимо указать поле **АдресДоставкиИД**, в ином случае возникнет ошибка.
-   **Сумма** — Сумма заказа, только числовое значение как int, так и float. Для float символ разделитель дробной части точка — .
-   **Вес** — Вес заказа, только числовое значение как int, так и float. Для float символ разделитель дробной части точка — .
-   **Статус** — Статус заказа из 1С, может быть только следующих значений:

[filename](../_order_statuses.md ":include :type=code text")

-   **Товары** — Список товаров из 1С, каждый элемент списка/массива должен иметь следующие 5 полей:
    -   **НоменклатураИД** — ID товара из 1С в формате UUID.
    -   **Характеристика** — Текст описание,
    -   **ВидНоменклатурыИД** — ID типа номенклатуры из 1С в формате UUID.
    -   **Количество** — Количество, только целое числовое значение — int.
    -   **ПроцентБонуса** — Процент бонуса, только целое числовое значение — float, int.

Если одно из полей будет заполнено некорректно, то заказ не будет создан и произойдет ошибка.

-   **НестандартнаяДоборка** — Список нестандартных товаров, каждый товар содержит 2 поля:
    -   **Описание** — любой текст описания.
    -   **Количество** — числов в формате int.
-   **НестандартнаяДоборкаПрикрепленныеФайлы** — Список прикрепленных файлов для нестандартной доборки, каждый файл/элемент может содержать 3 поля:
    -   **НазваниеФайла** — любой текст.
    -   **РасширениеФайла** — расширение файла, может быть только одним из допустымых форматов: 'doc', 'rar', 'zip', '7z', 'pdf', 'xlsx', 'xls', 'jpg', 'png', 'jpeg', 'gif'.
    -   **ДанныеФайла** — контент файла в формате Base64

**Необязательные поля**:

-   **Комментарий** — любой текст для комментария к заказу
-   **АдресДоставкиИД** — ID адреса доставки из 1С в формате UUID, добавится в заказ только при условии указания поля **Доставка** в значение 1.

## Результат выполнения

В случае успешного выполнения запрос, ответ будет: **Заказ успешно создан**

## Ошибки

Наиболее нестандартные ошибки:

-   **Поле — Данные — пустое** — может возникать если данные не содержат корневое поле **Данные**, либо если структура запроса нарушена синтаксически, то есть некорректная JSON структура.
-   **Произошла ошибка при создании заказа** — означает что, что-то произошло при сохранении данных, но это не относится к структуре запроса и данных в нём.
-   **Произошла ошибка при создании заказа — Головной контрагент отсутствует** — означает что есть проблема с базой данных и отсутствием нужной таблицы для создания заказа
-   **Произошла ошибка при создании заказа — ПользовательИД отсутствует** — Пользователь с ID указанным в поле **ПользовательИД** отсутствует.
-   **Или поле Товары, или поле НестандартнаяДоборка должно быть заполнено** — у заказа должны быть заполненны поля с товарами.

Остальные ошибки содержат конкретику по возникшей проблеме.
